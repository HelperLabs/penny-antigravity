# Changelog

## 0.1.0

Initial native Antigravity plugin for Penny, with OAuth MCP configuration, the canonical skill, a conversation eligibility rule, and static recall/save guidance. Hooks do not access private memory or enforce model compliance.

Verified on CLI 1.3.3 with native OAuth and per-call permissions, a refused write, and a disposable write/read/delete round trip. Includes instructions to protect the host's local credential files.
